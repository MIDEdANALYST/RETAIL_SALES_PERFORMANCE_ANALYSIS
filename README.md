\# RETAIL SALES PERFORMANCE ANALYSIS



\## 1. Project Overview



The Retail Sales Performance Analysis project is an interactive dashboard developed using Microsoft Excel to analyse retail sales data over a 12-month period, from January to December 2025.



The project demonstrates the process of transforming raw sales data into meaningful business information through data cleaning, analysis, visualisation and reporting.



\## 2. Project Objectives



The main objectives of this project are to:



\- Evaluate overall retail sales and profit performance.

\- Identify monthly sales and profit trends.

\- Compare sales performance across different branches.

\- Analyse product and category performance.

\- Understand customer purchasing patterns.

\- Examine payment methods and sales representative performance.

\- Present key business metrics through an interactive dashboard.

\## 5. Key Performance Indicators (KPIs)



The dashboard presents four major performance indicators:



\- Total Net Sales

\- Total Profit

\- Total Transactions

\- Average Net Sales



\## 6. Analysis Performed



The project examines the following areas:



1\. Monthly Sales and Profit Trends

2\. Branch Performance

3\. Category Performance

4\. Payment Method Analysis

5\. Customer Type Analysis

6\. Sales Representative Performance

7\. Top Five Products by Net Sales



\## 7. Dashboard Features



The interactive dashboard includes:



\- KPI cards for monitoring overall performance.

\- Monthly sales and profit trend visualisation.

\- Branch and category performance comparisons.

\- Product and customer analysis.

\- Sales representative performance analysis.

\- Interactive slicers for filtering results.

\- Timeline for date-based analysis.
